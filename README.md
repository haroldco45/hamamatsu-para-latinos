# Hamamatsu para Latinos 🇯🇵🌎

Guía de supervivencia bilingüe (español / English, con frases en japonés) para latinos que llegan a Hamamatsu (Shizuoka, Japón).
PWA instalable, hecha en HTML + JavaScript puro, sin servidor propio. Parte de la serie **Latinos por el Mundo**.

**Desarrollada por Vibras Positivas HM — Derechos de Autor Reservados**

🔗 https://haroldco45.github.io/hamamatsu-para-latinos/

## Datos verificados (octubre 2026)

- Salario mínimo de Shizuoka: ¥1.154 por hora desde el 15 de octubre de 2026.
- Línea de consultas laborales en español del Ministerio de Trabajo: 0570-001-704 (lun–vie 10:00–15:00) y 0120-531-404 (jue–vie 17:00–22:00, sáb 9:00–21:00).
- Colombianos y peruanos necesitan visa para Japón; mexicanos y brasileños entran como turistas sin visa.
- Multas a bicicletas con "boleta azul" desde el 1 de abril de 2026.

## Publicar en GitHub Pages

1. Crea el repositorio `hamamatsu-para-latinos` en github.com/haroldco45.
2. Sube los 7 archivos: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `og-image.png`, `README.md`.
3. Settings → Pages → Branch `main` / root → Save.
